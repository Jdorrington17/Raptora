# Raptora development roadmap

## Phase 0 — Public repository controls
- [ ] Review and merge documentation/governance baseline
- [ ] Enable suitable branch protections/rulesets in GitHub Settings
- [ ] Review external activity and repository notification settings
- [ ] Confirm security reporting channel and outside-contribution licensing policy

## Phase 1 — Source release clearance
- [ ] Verify intellectual-property/publication authority
- [ ] Scan legacy files, commit history and artifacts for restricted information
- [ ] Reconcile integration branch, open PRs and installer lineage
- [ ] Publish only approved, sanitised source

## Phase 2 — Reproducible engineering
- [ ] Match CI to actual source tools and lockfile
- [ ] Add application test, typecheck and build jobs
- [ ] Add controlled Windows installer test and recovery checks
- [ ] Introduce auditable version/release manifest

## Phase 3 — Validated delivery
- [ ] Complete connected acceptance in an authorised isolated environment
- [ ] Verify update/repair/rollback and persisted data
- [ ] Complete release/security/brand approvals
- [ ] Release by separately authorised process

Checklist completion must reflect actual recorded evidence, not inferred progress.
